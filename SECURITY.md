# Security Policy

## Reporting a vulnerability

**Don't open a public issue.** Email **nkrebs720@gmail.com**.

Include:

- A description of the issue
- Steps to reproduce (or a proof-of-concept)
- The commit SHA you tested against

Acknowledgement within 7 days.

## Supported versions

`main` is the only supported branch. Fixes ship from there and deploy automatically via Cloudflare Pages.

## Scope

In scope: the deployed app, the code in this repository, the public Supabase RPCs.

Out of scope: third-party services (Cloudflare, Supabase managed infrastructure, ESPN scores API), browser-vendor issues, issues requiring physical device access.
